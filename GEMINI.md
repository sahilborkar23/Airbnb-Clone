# Gemini Configuration

This file provides system instructions for Gemini interaction in this repository.

## Project Stack
- **Framework**: React (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Custom extracted SVGs (`src/assets/icons/AmenityIcons.jsx`)

## AI Guidelines
- Prioritize visual fidelity (pixel-perfect layouts).
- Use `px-10 md:px-20` for standard container padding.
- Always use the predefined Tailwind color variables (`#222222`, `#717171`) instead of arbitrary colors.
- All new SVGs must be extracted from the original Airbnb DOM and placed into the custom icon library. No third-party generic icons.
